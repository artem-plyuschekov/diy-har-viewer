# HAR Lens

Нативный просмотрщик HTTP Archive для macOS 13 и новее, Apple Silicon и Intel. Показывает список запросов, заголовки, параметры, тела запроса и ответа, время выполнения. Работает без сетевых обращений: содержимое HAR остаётся на вашем компьютере. История хранит только пути к успешно открытым файлам.

## Запуск

Распакуйте `HAR-Lens-macOS.zip` и перенесите `HAR Lens.app` в «Программы». Откройте приложение, выберите HAR через «Открыть» (`⌘O`) или перетащите файл в окно. Недавние файлы доступны на начальном экране и в боковой панели. Используйте поиск, затем выберите запрос, чтобы посмотреть подробности.

Чтобы открывать `.har` двойным кликом в Finder, при необходимости один раз выберите файл → «Свойства» → «Открывать в приложении» → HAR Lens → «Настроить». Приложение само не меняет глобальную ассоциацию файлов.

Сборка подписана локальной ad-hoc подписью, без Developer ID и нотариализации Apple. Данные аккаунта Apple, сертификаты и ключи не используются. На другом Mac Gatekeeper может заблокировать первый запуск. Если вы доверяете источнику приложения, после попытки запуска откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Этот шаг подтверждает запуск конкретного приложения; настройки защиты системы менять не нужно.

## Сборка и передача

Нужны macOS и установленные Xcode Command Line Tools со Swift. Из каталога проекта:

```bash
swift test
bash scripts/build-app.sh
```

Результаты: `dist/HAR Lens.app` и `dist/HAR-Lens-macOS.zip`. Скрипт собирает обе архитектуры, проверяет универсальный бинарный файл и подпись, затем создаёт ZIP. Для передачи отправьте ZIP; HAR отправляйте отдельно и только после проверки, поскольку он может содержать cookies, токены и персональные данные.

Для установки используйте приложение из ZIP и локальную папку «Программы». В синхронизируемой папке iCloud к `.app` могут повторно добавляться метаданные Finder, мешающие проверке подписи. Архив создаётся и проверяется до переноса в такую папку; извлечённая в локальную папку копия прошла проверку подписи. Работа на Intel и macOS 13 проверена сборкой, без запуска на этих системах.
